# Known Issues

This build is ready to use, but there are still a few things to keep in mind.

## Current Notes

1. Linux release packaging is ready now. Windows packaging is still to come.
2. Some older compatibility paths are still part of the shipped plugins.
3. Some lower-level edit helpers are still being cleaned up behind the scenes.

## Practical Takeaway

For normal shot work, the main question is simple: does the tool stay responsive and predictable for the task in front of you?

Right now the answer is generally yes for the main painted-scatter flow, but this is still an actively improving plugin set.

If you need the deeper notes for debugging, use the developer pages linked from the home page.
